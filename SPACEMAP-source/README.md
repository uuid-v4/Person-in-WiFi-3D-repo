# SPACEMAP

**실내 공간·동작 시각화 — Wi-Fi 센싱 연동을 위한 2D·3D 프로토타입**

재난구조·안전 목적의 해커톤용 가상 시연입니다. 준비된 건물 모델과 가상 관측 데이터를 바탕으로, 진입 전 관측부터 이동·현장 확인·기록까지의 화면 흐름을 보여줍니다.

**[웹 시연 열기](https://spacemap-rescue-demo.nest931008.chatgpt.site)** — 설치 없이 브라우저에서 실행할 수 있습니다.

## 시연 흐름

1. 지도에서 시연 건물 선택 → 내부 탑뷰 전환 → **사전 관측** 실행
2. 점멸 지점을 선택해 가상 관측 정보 확인 → **진입 시작**
3. **R2/P2 → R3/P3 → R1/P1 → R4/P4** 순서로 라우터 클릭: 화살표 이동, 누적 점선, 구역 공개
4. 각 지점 도착 후 점을 선택하고 **확인**: 스켈레톤 표시와 인원 집계
5. 스켈레톤 선택: 확대 후 5초 가상 관절 동작 재생, 3D 전체 시점 복귀
6. **기록**에서 선택 메모 작성, 모든 지점 확인 후 최종 결과 조회

이동 중에도 2D·3D 전환과 카메라 회전·확대·화면 이동이 가능합니다. 일시정지 중에도 카메라를 조작할 수 있습니다. 기록과 메모는 **해당 브라우저의 현재 시연 회차에만 유지**되며 새로고침·초기화하면 사라집니다.

## 로컬 실행

저장소를 내려받아 `index.html`이 있는 폴더에서 실행합니다. Python 3와 WebGL을 지원하는 최신 브라우저가 필요합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Windows에서는 `python3` 대신 `py`를 사용할 수 있습니다.

브라우저에서 **[http://127.0.0.1:8765/index.html](http://127.0.0.1:8765/index.html)** 을 엽니다. 서버 종료는 터미널에서 `Ctrl+C`입니다. 포트가 사용 중이면 명령과 접속 주소의 `8765`를 다른 번호로 바꿉니다.

- `index.html`을 더블클릭하지 말고 HTTP 서버로 실행하세요.
- npm 설치·빌드·로컬 LLM·API 키는 필요하지 않습니다.
- 첫 접속 시 모델 로딩을 기다려 주세요. 지도 타일을 불러오려면 인터넷 연결이 필요합니다.
- 로컬 코드 수정은 공개 사이트에 자동 반영되지 않습니다. 공개 버전 갱신에는 별도 재배포가 필요합니다.

## 코드 구성

| 파일·폴더 | 역할 |
|---|---|
| `index.html`, `demo.css` | 화면 구성·디자인 |
| `app.js` | 시연 진행, 선택·확인, 기록·메모·최종 결과 |
| `building-view.js` | 모델, 카메라, 스켈레톤과 시각 효과 |
| `entry-view.js`, `reveal.js` | 진입 화살표·이동 경로·구역 공개 |
| `map-view.js` | 지도와 건물 선택 |
| `observation-sample.js`, `pose-sample.js` | 가상 관측·관절 샘플 처리 |
| `preparation/` | 배치·시연 설정, 14점 관절 정의, 5초 동작 데이터·인원 모듈 |
| `assets/models/`, `load-model.js` | 압축·분할 모델과 실행 시 복원·로딩 |
| `vendor/` | Three.js·Leaflet 실행 라이브러리와 라이선스 |

모델은 손실 없이 압축·분할되어 있으며 실행 시 자동 복원됩니다. 이 저장소에는 시연 실행용 파일을 담았습니다. 제작 프롬프트, 모델 변환 도구, 원본 SketchUp 파일, 준비용 확인 페이지는 포함하지 않습니다.

## 현재 범위와 출처

- 내부 구조·라우터·인원 배치와 관측·동작은 **준비된 모델과 고정 가상 데이터**입니다.
- 실제 Wi-Fi 신호 수신, 사람·위치·동작 추론, 실시간 센서 연동, 로컬 LLM, 단말 간 상태 공유는 구현하지 않았습니다.
- 지도에서 선택한 장소와 ANSEN 예시 모델은 별개이며, 해당 실제 장소의 내부 도면을 나타내지 않습니다.
