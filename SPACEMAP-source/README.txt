SPACEMAP — 팀 공유용 소스 코드

공개 시연과 같은 HTML/CSS/JavaScript 소스, 모델, 가상 데이터와 실행 라이브러리를 포함합니다.
웹 시연: https://spacemap-rescue-demo.nest931008.chatgpt.site

1. 실행
- ZIP을 풀고 SPACEMAP-source 폴더를 엽니다.
- Python 3가 설치된 컴퓨터에서 터미널을 열고 이 폴더로 이동합니다.
- macOS/Linux: python3 -m http.server 8765 --bind 127.0.0.1
- Windows: py -m http.server 8765 --bind 127.0.0.1
- 브라우저에서 http://127.0.0.1:8765/index.html 에 접속합니다.
- 종료할 때는 서버를 실행한 터미널에서 Ctrl+C를 누릅니다.
- 8765 포트를 이미 사용 중이면 8767 등 다른 번호로 실행하고 접속 주소도 맞춥니다.
- index.html을 더블클릭하는 방식은 사용하지 않습니다. 모델과 데이터 로딩에 HTTP 서버가 필요합니다.
- npm 설치나 빌드, 로컬 LLM, API 키는 필요 없습니다. Python 자체는 이 ZIP에 포함하지 않았습니다.
- 최신 브라우저와 WebGL을 사용합니다. 첫 접속에서는 모델 로딩을 기다립니다. 지도 타일에는 인터넷 연결이 필요합니다.

2. 시연 순서
건물 클릭 → 사전 관측 → 진입 시작 → R2/P2 → R3/P3 → R1/P1 → R4/P4.
각 지점은 도착 후 점을 선택하고 '확인'을 눌러야 스켈레톤과 인원 집계로 바뀝니다.
스켈레톤을 클릭하면 확대 후 5초 가상 동작을 재생하고 3D 전체 시점으로 돌아옵니다.
'기록'에서 선택 메모를 작성하고 모든 지점 확인 후 최종 결과를 봅니다.
기록·메모는 해당 브라우저의 현재 회차에서만 유지되며 새로고침·초기화 시 사라집니다.

3. 코드 위치
- index.html / demo.css: 화면 구성과 디자인
- app.js: 시연 진행, 선택·확인·기록·메모·최종 결과
- building-view.js: 3D 모델, 카메라, 스켈레톤과 시각 효과
- entry-view.js / reveal.js: 진입 화살표·누적 경로와 구역 공개
- map-view.js: 지도
- observation-sample.js / pose-sample.js: 가상 관측과 관절 샘플 처리
- preparation/: 배치·시연 설정·14점 관절 정의·5초 관절 데이터와 인원 모듈
- assets/models/: 압축·분할된 모델과 파일 목록
- load-model.js: 모델 조각을 합치고 압축을 풀어 원본 GLB를 로딩
- vendor/: 실행에 필요한 Three.js·Leaflet과 각 라이선스

4. 보존 범위와 수정
- 현재 공개 시연의 실행 코드와 데이터입니다. 원본 작업 폴더나 공개 사이트를 직접 수정하지 않는 독립 사본입니다.
- 모델은 배포 크기 제한 때문에 손실 없이 압축하여 두 파일로 나눴습니다. 실행 시 자동 복원하므로 별도 모델 변환은 필요 없습니다.
- 코드 변경 후 브라우저를 새로고침합니다. 이 폴더를 수정해도 공개 사이트에는 자동 반영되지 않으며 별도 재배포가 필요합니다.
- 프롬프트·Python 가상환경·모델 변환 도구·원본 SketchUp 파일·준비용 확인 페이지·게시 계정 설정·Git 이력은 포함하지 않았습니다.

5. 현재 기능의 의미
- 재난구조·안전 목적의 해커톤용 가상 시연입니다.
- 구조·라우터·인원 위치·관측·관절 동작은 준비된 모델과 고정 가상 데이터입니다.
- 실제 Wi-Fi 수신·사람 추론·실시간 센서 연결·로컬 LLM·단말 간 상태 공유는 구현하지 않았습니다.
- 선택한 지도 장소와 ANSEN 모델은 별개입니다. 해당 실제 장소의 내부 도면으로 해석하지 않습니다.
- 지도 출처 표시와 vendor 내 서드파티 라이선스를 유지합니다. 이 안내는 모델이나 전체 프로젝트의 별도 이용허락을 새로 부여하는 문서가 아닙니다.
